# Chorradas Geniales 🤡💰

Aplicación web para descubrir productos absurdos, tontos o random de internet que, por pura originalidad y gracia, se acabaron vendiendo a lo bestia (Pet Rock, Snuggie, el pepinillo cantor, Crocs...).

## Funcionalidades

- Catálogo curado de productos reales con descripción, categoría, año, precio aproximado, ventas y "por qué triunfó".
- Búsqueda por nombre, descripción o categoría.
- Filtro por categoría y ordenación (nivel de chorrada, ventas, año, alfabético).
- "Chorrómetro" (nivel de 1 a 5) para medir lo absurdo de cada producto.
- Botón "Sorpréndeme" para descubrir una chorrada al azar.
- Favoritos guardados en el navegador (localStorage).
- Formulario para proponer tus propias chorradas, guardadas localmente.

## Cómo usarla

Es una web estática sin dependencias. Basta con abrir `index.html` en el navegador, o servirla con cualquier servidor estático:

```bash
python3 -m http.server 8000
```

Y visitar `http://localhost:8000`.
